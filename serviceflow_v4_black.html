ServiceFlow V4
System Overview

A credit-based retainer management system for service businesses. Built on Google Sheets + Google Apps Script with custom HTML/JS client interfaces and Zapier/FreeAgent integrations.

Google Sheets · Data Layer Google Apps Script · Backend HTML / JavaScript · Client UI Zapier · Project Mgmt FreeAgent · Invoice Linking

QOF Sheets
ON PLAN
Quarterly Business Plan
Standard retainer services scheduled within the monthly plan cycle. Credits deducted only when status → In Progress.
OFF PLAN
Emergency / Priority
Urgent requests outside the plan. Emergency capped at 2 months of credits. Payment is 100% credits OR 100% cash — never hybrid.
REVISION
Correction Work
Corrections and amendments. Can borrow from next quarter credits or pay cash. Any interruption requires client re-request.

Quarterly Form System — Sheets 26–30
System Overview: Sheet 27 (Q_Options) is the master service pool. Sheet 26 (Quarters) owns all duration definitions. Sheet 28 (Q_Options_Strat) slices the pool by duration into named strategies. Sheet 29 (Q_Options_Strat_Services) pins services to months. Sheet 30 (Q_Order_Links) is the URL factory for embed links.
26
Quarters
Quarter and duration definitions. Single source of truth for month ranges. All downstream quarterly lookups use q_months_final (col G). A new row is needed per distinct duration variant of the same quarter.
⌄
ColFieldKeyType / SetupNotes
Aq_idPKAuto-increment=IF(B2<>"",MAX($A$1:A1)+1,"")
Bq_nameText / Formulae.g. Q2 2026 — can use ="Q"&C2&" "&D2
Cq_numberNumber1–4
Dq_yearNumbere.g. 2026

Fq_months_manual_overrideTextBlank for standard quarters. Populate for partials e.g. 5,6

Key rule: A new q_id row is needed for each distinct duration variant — e.g. full Q2 = one row, 2-month partial Q2 = second row. Both can reference the same q_opt_id service pool in Sheet 27.
27
Q_Options
Master service pool for a client plan for a quarter. Contains ALL services available across ALL possible strategy groupings regardless of month duration. One row per service. q_opt_id is the grouping key referenced by all downstream quarterly sheets.
⌄

Jservice_name_descTextOptional. GAS uses as service description on form if populated.

Ldependency_overrideCheckboxTRUE = this Q_Options entry can be selected and submitted on the QOF form even if the service has an unmet requires_service_id dependency defined in Sheet 3 Services. Dependency checks are skipped for this option. Full behaviour documented in service prerequisites spec (Task B Pt.2).
Key rule: Do NOT create new Q_Options rows just to handle a 2-month or 1-month strategy. The service pool is shared. Duration is controlled via q_id → Sheet 26.
